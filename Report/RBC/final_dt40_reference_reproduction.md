## 2. z256 격자의 효율 (왜 이 격자인가)

- 벽수직만 256(BL 해상), 수평 128: 셀 수 1/4 (4.2M)
- **수평 성김이 CFL 지배항(u/Δx)을 절반으로** → dt 0.026 (256³의 0.0065 대비 4배)
- 합계: **256³ 대비 t.u.당 ~15배 저렴** — 냉시작 t=25,000이 GPU 2장 ~8시간
- 256³ 대비 정확도 손실 없음 (Run B 256³ 결과와 참조 밴드에서 합류)

## 3. 전체 원인 사슬 (P5의 −12%는 무엇이었나)

P5(256³, 냉시작, CFL=1.0, np3=2, 구 nstat)가 θ_c=0.118~0.122로 낮았던 원인 분해:

1. **CFL=1.0 정책 병리 (주범, Run C로 실증)**: dt는 CFL=0.3과 같게 자기제한되면서
   근벽 한계 모드만 3배 진폭으로 여기(host_max 47→154) → BL 교란 + 클리핑
   (140셀/스텝) → E22 상태를 0.128→0.1240으로 침식. **정책이 dt가 아니라 "허용
   잡음 진폭"을 정한다** — 같은 dt에서 MaxCFL 설정만으로 답이 갈리는 이유.
2. **np3=2 심 버그 (D5, 수정됨)**: z-벽 마스크가 소유권 체크 없이 중앙 심(θ_c 면)에
   발화 — np=1과 np3=2가 다른 연산자를 풀고 있었음.
3. **냉시작 미수렴**: E22/Run B 계열이 보여준 대로 이 계는 t 15,000+ 필요.

역으로 "잘 나오는" 조건: **CFL≤0.3(모드 휴면) + 수정 바이너리 + 충분한 물리시간** —
코드 자체(재배열+Report/36 수정+D2/D5)는 Run B/C/P7b 모두에서 무죄를 넘어
참조 재현을 달성.

## 5. 남은 개선 로드맵 (정확도 아닌 강건성)

1. **클립-off A/B**: 정상상태 발화 0이므로 제거해도 안전할 가능성 — 냉시작 과도기
   안전만 확인하면 논문 정합성 항목 하나 제거
2. **θ→0 A/B**: 상삼각 사후보정 자체를 끄고 CFL-정책 독립성 확인
3. **외부 반복(monolithic화)**: 명시 채널 원천 제거 — CFL 상향의 문을 다시 여는 길
4. **D1+D4+D6 세트** (물성 미분 ΔT 인자 + 벽 dκ̂ 잔차 + 벽 폐합 일관화): 논문 정합
   마무리 — 반드시 동시 수정 + 전용 A/B
5. E22-era 대비 검증에 쓴 자산 정리: restart_runb(t 10,600), restart_p7b(t 25,000,
   평형) — 이후 웜체인 출발점
