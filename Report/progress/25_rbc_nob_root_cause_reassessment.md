## 1. 이번 세션에서 새로 확인한 사실

### 1.1 PaScaL의 "OB 투영(Cmp=1)"은 원본이 아니다

`PaScaL_TCS/src/module_solve_pressure.f90`은 git 작업트리에서 **수정된 상태**다. `git diff` (요지):

```fortran
! ── Poisson RHS ──
-  PRHS(i,j,k) = (DivUm - cbc)/dt/Cmp + ExtraTerm
+  PRHS(i,j,k) = (DivUm - cbc)/dt/Cmp ! + ExtraTerm disabled for stability test

! ── 속도 투영 (원본, git HEAD) ──
-  invRhoc = 0.5d0/dmx1(i)*(dx1(i)*invRho(im,j,k) + dx1(im)*invRho(i,j,k))
-  U(i,j,k) = U(i,j,k) - dt*Cmp*( (dP(i,j,k) - dP(im,j,k))/dmx1(i) &
-             + (invRhoc - 1.d0)*(dPhat(i,j,k) - dPhat(im,j,k))/dmx1(i) )
+  ! NOB projection disabled: only OB projection (invRhoc term removed)
+  U(i,j,k) = U(i,j,k) - dt*Cmp*(dP(i,j,k) - dP(im,j,k))/dmx1(i)
```

즉 **원본 PaScaL은 속도 투영에 `(invRhoc−1)·∇dPhat` 항을 포함**한다 — 포트의 수정 전
`project_nob_`와 정확히 동일한 형태다. Report 24 §6.2가 인용한 "PaScaL 실제 코드(§804-817,
Cmp=1.0) = OB 투영"은 **§3.8의 발산 우회 과정에서 본인이 수정해 둔 파일**을 원본으로 오독한 것이다.
따라서 "PaScaL은 ExtraTerm+OB 투영으로 설계했는데 포트가 NOB 항을 중복 추가했다"는 진단의
전제가 무너진다. **포트(수정 전)가 오히려 원본에 충실했다.**

### 1.2 원본 스킴은 이중계산이 아니라 정확한 상쇄 짝이다

원본 스킴 (dP̂ = 이전 스텝 δp의 2차 외삽):

```
Poisson :  ∇²δp = ∇·u*/dt + ∇·[(1−1/ρ̂)·∇dP̂]      (= PRHS + ExtraTerm)
투영     :  u ← u* − dt·[ ∇δp + (1/ρ̂−1)·∇dP̂ ]
```

투영 후 발산:

```
∇·u = ∇·u* − dt·[ ∇²δp + ∇·((1/ρ̂−1)∇dP̂) ]
    = ∇·u* − dt·[ ∇·u*/dt + ∇·((1−1/ρ̂)∇dP̂) + ∇·((1/ρ̂−1)∇dP̂) ]
    = 0        (두 NOB 항이 부호 반대로 정확히 소거)
```

이것이 상수계수 Poisson(FFT 가능)으로 가변밀도 투영 `u ← u* − dt·(1/ρ̂)∇δp`를 구현하는 고전적
**pressure-splitting**이다. ExtraTerm과 투영의 NOB 항은 **한 쌍**이며, 함께 있어야 ∇·u=0이
기계정밀도로 성립한다 (실제 수정 전 포트의 monitor div ≈ 7×10⁻¹¹이 그 증거. 포트
`pressure_engine_gpu.cuh:1376-1378`의 "REQUIRED … to **cancel** across MPI boundaries" 주석도
같은 이해를 기록하고 있다).

**크기 논증**: 두 항의 실효 크기는 `(1−1/ρ̂) ≈ a11·ΔT·θ ≈ ±0.5%` (벽 기준). Poisson과 투영을
합친 순효과 = OB 투영 대비 `(1/ρ̂−1)·dt·∇δp̂` ≈ 보정량의 0.5%. **0.5% 항이 θ_c를 85% (0.040→0.074)
바꿀 수 없다.** Report 24 §5도 같은 항을 "θ_c에 미치는 영향은 작을 것"으로 추정했으면서 §6에서
같은 항을 주범으로 지목한 내부 모순이 있었다.

### 1.3 검증 런이 실증적으로 반증한다 (2026-07-02 완료)

`scripts/rbc_nob_fix_verify.sh` → `apps/rbc/fig9_nob_gpu_fix/` (128³, Γ=6, γ₃=2.6, ΔT=20K,
200K steps). 이 런은 투영 수정을 넘어 **NOB 압력 경로 전체를 OB로 교체**한 상태였다
(`main_gpu_nob.cu` G4: `solve_pressure_nob_gpu` → `solve_pressure_gpu`; div ≈ 8×10⁻¹¹로 확인).

| step | t | θ_c (누적) | Nu |
|------|-----|-----------|------|
| 200,000 | 3175.8 | **0.0355** | 11.07 |

순간값 역산(§1.4 방법): **inst θ_c ≈ 0.045 @ t=3176** — 수정 전 500K 런의 같은 시각 값과
사실상 동일(§1.4 표). **예상했던 0.074 회복은 일어나지 않았다.** 결론: NOB 압력 처리는
(전체를 켜든/끄든/반만 끄든) θ_c에 ~수 % 이하의 영향 — §1.2의 크기 논증과 정합.

### 1.4 누적평균 vs 순간값 — 수렴 상태 재평가

monitor.csv의 `Theta_c`는 **nstat_start 이후 누적 시간평균**이다. 초기 과도가 평균을 끌어내리므로
순간값을 역산했다: `inst(t) ≈ m(t) + (t−t₀)·dm/dt` (m=누적평균, t₀=통계 시작 시각).

수정 전 500K 런 (`fig9_nob_gpu_out_20_x`, t₀≈717):

| t | m (누적) | inst (역산) |
|------|--------|------------|
| 1438 | 0.0244 | — |
| 2871 | 0.0312 | ≈ 0.040 |
| 4308 | 0.0363 | ≈ 0.047 |
| 5751 | 0.0392 | ≈ 0.048 |
| 6470 | 0.0400 | ≈ 0.046 |
| 7185 | 0.0406 | ≈ 0.046 |

**순간값은 t ≳ 4000부터 0.046 ± 0.002로 플래토.** 시간 적분을 더 늘려도 0.074에 접근하지 않는다
— 시간수렴 부족은 (누적평균 기준 수치를 낮춰 보이게 했을 뿐) 잔여 1.6× 결손의 원인이 아니다.

ΔT=40K 런(`fig9_nob_gpu_out_40_x`, 350K steps, t=4080): m=0.0694, inst ≈ 0.09 (아직 상승 중).
**논문 대비 배율: ΔT=20K → 0.046/0.0744 ≈ 1.6×, ΔT=40K → ~0.09/0.135 ≈ 1.5×.**
누적평균으로 보였던 "ΔT 클수록 배율 증가"(1.58→2.04×)는 통계 미수렴 아티팩트였고, 순간값
기준으로는 **배율이 ΔT에 걸쳐 대략 일정(~1.5–1.6×)** 하다. 특정 비선형 항 누락(ΔT에 따라
커져야 함)보다 **균일 스케일 계통 차이**를 시사한다.

### 1.5 물리시간 정합 비교 — 포트 ≡ 저장소

| 코드 / 격자 | 물리시각 t | θ_c |
|------------|-----------|-----|
| PaScaL 저장소 64³ (OB 압력) | 1340 | 0.027 |
| 포트 128³ (NOB 압력) | 1438 | 0.024 |

**같은 상승 궤적 위의 두 점이다.** Report 24 §3이 "격자 의존성(64³ 0.027 → 128³ 0.040)"으로
읽은 것은 대부분 **적분 시간 차이**였다(PaScaL 런은 t=1340에서 멈췄고, 그 시각의 포트 값과 일치).
같은 이유로 **gamma 스캔(Report 23 §1.1)도 재해석 필요**: 등스텝 비교에서 γ=3.5는 벽 셀이
얇아 dt가 작고 → 같은 스텝 수에서 물리시간이 짧아 → θ_c가 낮게 보인다. "γ를 키우면 θ_c가
내려간다"는 결론은 물리시간 혼동일 가능성이 높다 (우선순위는 낮지만, 향후 모든 비교는
**등 물리시간**으로 할 것).

**종합**: 줄단위 코드 대조(Report 23) + 물리시간 정합 실구동 일치 → **포트는 저장소를 충실히
재현한다**는 결론이 더 강해졌다. 결손 1.6×는 포트 버그가 아니라 **저장소(=포트) 계열 전체 vs
논문 값**의 차이다.

## 4. 남은 가설 (우선순위)

전제: 포트 ≡ 저장소이고, 수렴 순간값 θ_c ≈ 0.046 vs 논문 0.0744 (1.6×, ΔT에 걸쳐 대략 일정).

**H1. 물성 다항식/모델이 논문 실제 사용본과 다름 (유력)**
저장소는 glycerol 블록을 **주석 처리한 채 출고**했다 (PaScaL `module_global.f90:131-134`,
MPM-STD `core_momentum.f90:400`) — 출고본 계수는 논문 프로덕션 런과 다른 버전일 수 있다
(한 번도 저장소 상태로 재검증된 적 없음). 점성비 4.16×는 Cheng 2008과 맞지만(Report 23 §1.4),
θ_c는 ν(T)의 **함수 형태**와 κ(T)·α(T)·cp(T) 비대칭에도 민감하다. 논문이 인용한 물성 원천
(Horn & Shishkina 2013 부록의 glycerol 피팅)과 5개 다항식 전부를 계수 단위로 대조해야 한다.

**H2. 논문 설정/정의 차이**
Ra 정의(물성 평가 기준 온도), Γ, 격자/스트레칭, θ_c 정의(순간 플래토 vs 시간창 평균), 초기장,
그리고 **Nu 교차검증**(포트 Nu = 10.8@ΔT=20K — 논문이 같은 케이스의 Nu를 제시하면 유동 자체의
일치 여부를 θ_c와 독립적으로 판정 가능).

**H3. 참조값의 성격**
`fig9_data/PaScaL_TCS.csv`(0.0744/0.1350/0.1900)는 BL 이론(Zhang/Ahlers/Horn)과 정확히 일치한다.
Fig 9에서 이론 곡선이 아닌 **DNS 심볼**을 디지타이즈했는지 재확인 필요. "이론 vs DNS"의 계통
차이는 §1.4의 **일정 배율** 관찰과 부합한다. (Report 24 §6.1은 DNS로 확인했다고 하나, 같은
세션에서 §6.2 오독이 있었으므로 재검증 가치가 있다.)

## 5. 실행 계획 (비용순 · 판별력순)

**P0 — 포트 원복** (§3). GPU 추가 실험 불필요: "NOB 압력 vs OB 압력" A/B는 이미 사실상 완료
(§1.3, 차이 없음).

**P1 — BL 이론 계산기 (GPU 0, 반나절, 가장 판별력 높음)**
Ahlers et al. 2006 / Horn & Shishkina 2013의 2-경계층 모델을 수치로 구현하고 **저장소 다항식
그대로** 넣어 θ_c(ΔT=20/40/60)를 예측한다.
- 예측 ≈ 0.0744/0.135/0.190 → 물성은 논문과 동등 → 결손은 수치/설정(H2) 또는 참조 성격(H3).
- 예측 ≈ 0.046 계열 → **저장소 물성이 논문보다 약함** → H1 확정, P4로.

**P2 — 문헌 3점 대조 (문헌 접근만 필요)**
Kim et al. 2023 본문/표 + Horn 2013 부록에서 (i) glycerol 물성 피팅 계수 전체, (ii) Ra/Γ/격자/
θ_c 정의, (iii) 해당 케이스의 **Nu**·θ_c 수치를 추출 → 포트의 (μ비 4.16×, Nu 10.8, θ_c 0.046)과
대조. Horn 2013 자체의 glycerol θ_c(실린더 Γ=1이지만 독립 DNS)로 0.074의 타당성도 삼각측량.

**P3 — PaScaL 원본 128³ 실구동 (CPU, 발산 디버그 선행)**
`git restore src/module_solve_pressure.f90` 후 **원본 그대로**(ET + NOB 투영 짝) 재시도.
논문이 이 코드로 돌았으므로 원본 조합은 돌아야 한다 — 기존 발산(step~25)은 로컬 수정 조합
(짝 깨짐) 또는 설정(부력축 교체, Γ 매핑, dPhat ghost) 산물일 가능성을 원본 기준으로 재조사.
성공 시 128³을 **등 물리시간**으로 포트와 대조: ~0.046이면 "저장소 ≠ 논문" 최종 확정,
0.074면 포트에 숨은 차이가 있는 것 (현 증거상 전자가 유력).

**P4 — 계수 교체 실험 (H1 확정 시)**
Horn 피팅으로 다항식 교체 → ΔT=20/40 재실행 → 0.0744/0.135 재현 확인. 이것이 최종 fix.

**P5 — 측정 위생 (병행)**
- monitor에 **순간 θ_c 컬럼 추가** (누적평균만으로는 과도가 결과를 왜곡; §1.4).
- 모든 코드간·격자간 비교는 **등 물리시간** 기준으로.
- 통계 누적 시작(t_stat_start)을 순간값 플래토 이후(t ≳ 4000)로 상향.

## 부록 B. 순간값 역산 방법

누적평균 `m(t) = (1/(t−t₀))·∫_{t₀}^{t} θ_c(s) ds` 에서
`inst(t) = d/dt[(t−t₀)·m(t)] = m(t) + (t−t₀)·dm/dt`.
dm/dt는 monitor 인접 구간의 중앙차분. t₀ = 통계 시작 시각(nstat_start 스텝 도달 시각, 500K 런
기준 ≈717). 잡음 수준 ±0.002는 인접 구간 추정치의 산포에서.
