## 3. 격자 — 결정적 발견

### 3.1 프로덕션의 자체 격자 기준 (§3.2)
- η_K = Pr^{1/2}/[Ra(Nu−1)]^{1/4}, **η_B = η_K/Pr^{1/2}** (Pr>1);
  **max(h₁,h₂)/(π·max(η_K,η_B)) ≤ 0.426** 전 런 준수.
- 2D 벽수직: 균등비 스트레칭(글리세롤 비율 1.028, 최대 셀 종횡비 3.0).
- 2D G106(Ra=1e6, glycerol): **L=1×1 도메인, 128×128**, h₁=1/128, h₂=3.51e-3–1.03e-2,
  기준값 0.162. (h₂ 프로파일은 우리 tanh γ=2.6과 유사 — 첫 셀 ~0.003, 중앙 ~0.01.)

### 3.2 3D 케이스에 적용하면
η_B(Ra=1e6, Pr=2547, Nu≈9.6) = 0.933/50.47 ≈ **0.0185** → 허용 max h = 0.426·π·0.0185 =
**0.0247** → **Γ=6 수평에 ≥243점 필요.**
- Pan 2022 §3.3: 수평 균일("Kolmogorov/Batchelor 해상하도록"), 수직 hyperbolic 분포 [ref 5] —
  **격자 크기는 본문에 미기재**(!). 기준 준수를 명시했으므로 수평 ≥256이었을 것.
- **Kim 2023의 "128×128×128"(h=0.047)은 h/πη_B = 0.81로 자기 그룹 기준을 1.9× 위반** —
  이 격자 기술이 Table 5 수치를 만든 격자일 수 없음(재게재 시 기술 오류/단순화로 추정).
- 우리 기존 런들(수평 128)도 동일 위반; 스펙트럼 진단(Report 27 이후)으로도 분산의 8–15%가
  ½나이퀴스트 위 = 수평 한계해상 확인.
- **E7(256×256×256, h=0.0234 ≤ 0.0247 ✓)이 처음으로 기준 만족** — 프로덕션급 격자.

**§4.1 정정 (2026-07-03 오후)**: 포트 `k_pred_pgrad`의 주석("Matches PaScaL_TCS mom.f90:344-345")은
오독 — 원본 344-345는 invRhoc가 곱해져 있다. 포트의 이 함수는 DHVC 전용(물성≡1)이라 현재 무해하나,
**NOB-DHVC를 돌리게 되면 실버그** → invRhoc 추가 필요(후속 작업). PaScaL의 주석 처리된 물리는
V-방향 부력(RBC 전환 스위치)과 glycerol 계수 블록뿐 — thermal/pressure 모듈은 완전 활성. 스킴 차이
후보는 사실상 소진; 남은 판별 = E7(수평 해상도) → (잔여 시) 부록 B 벽항.

### 4.2 전 모듈 스캔 결과 — 논문 ≡ 공개 PaScaL (2026-07-03)

모멘텀 외 전 모듈을 스캔했다. **논문과 공개 PaScaL 구현은 일치**하며, 주석에 숨은 물리는 없다:
- `main.f90` 시간 루프: thermal_coeffi(Tⁿ)→thermal→momentum_coeffi(Tⁿ⁺¹)→dU→dV→dW→blockLdV→
  blockLdU→pseudoupdate→pressure — 포트(타이밍 수정 후)와 동일 순서, 숨은 단계 없음.
  **PaScaL에는 W 벽면 클램프가 없음** — 벽면 행을 mbc로 정식 처리하기 때문 (포트의 dW 버그가
  포트 고유 결함이었다는 방증).
- `module_global`: Cmu=√(Pr/Ra), Cmt=1, Ct=1/√(RaPr), Cmp=1 — 동일.
- `module_post`: ThetaC = 중앙평면(n2m/2) 수평평균, CFL/Div 표준 — 포트와 등가.
- **`module_mpi_subdomain` — 구조적 차이 발견**: 격자 face 공식은 동일 tanh이나, 벽쪽 고스트를
  `x(0)=x(1)`로 **벽 위에 붕괴**시킨다(폭 0 고스트, 논문 Fig B.1의 "x₂,₀=x₂,₁" 그대로) →
  Dirichlet이 정확히 벽에 부과. 포트는 미러 고스트 셀+고스트값 정책 — 유효 벽이 반 셀 이동
  (측정 ~0.3% 대칭, Report 26 §3.2). 부록 B의 mbc/ebc 벽항은 이 붕괴-고스트 좌표계 위에 정의됨.

### 4.3 포트의 "등가 처리" 인벤토리 (형식이 다르지만 등가로 취급한 것)

**검증되어 등가 확인**:
| 항목 | PaScaL/논문 | 포트 | 근거 |
|---|---|---|---|
| 축 매핑 | y=벽수직 | z=벽수직 | 줄단위 대조 (Report 23) |
| Poisson | FFT+TDMA | pencil FFT(x,y)+TDMA(z) | 검증됨 |
| θ_c 측정 | 단일 midplane | 두 중앙면 평균 | 차이 ~1e-4 |
| NOB 투영 짝 | (Λ−Λ⁰)∇φ* | (irc−1)∇dP̂ | 발산 정확 상쇄, div~1e-10 (Report 25) |

**등가 추정 — 완전 감사 미실시**:
| 항목 | PaScaL/논문 | 포트 | 상태 |
|---|---|---|---|
| 압력 경로 | 증분(van Kan): 예측자 −(1/ρ̂)∇P_acc + 투영 δp | **비증분(Chorin형)**: 예측자 압력 없음, 투영이 전체 압력 | 실효 힘 (1/ρ̂)∇p_total 동일하나 압력 분리 시간정확도 2차→1차. 준정상이라 무해 추정 — 미정량 |
| 벽 BC 구현 | 고스트 붕괴 + 명시적 mbc/ebc/cbc | 미러 고스트 + 정책 + TDMA 폴드 | 유효 벽 반셀 이동(0.3%). **NOB 벽 물성(μ̂,κ̂ 4×) 가중과의 상호작용 미감사** — E7 후 1순위 |
| dPhat 외삽 | δp 증분의 외삽 | 전체 압력의 외삽 | 형식 동일·의미 다름, 결과 등가 추정 |

**"등가"인 줄 알았다가 아니었던 것 (적발·수정)**:
- W 벽면 행: PaScaL은 mbc 정식 처리, 포트는 일반 행+사후 클램프 → **dW 누수 버그** (Report 27, 수정 완료).
- `k_pred_pgrad` invRhoc 누락: DHVC에선 우연히 등가(물성≡1), NOB-DHVC면 실버그.

**포트에만 있는 추가물 (등가 가정, 미검증)**:
- **T 클리핑** (`k_clip_T`, T∈[−0.5,0.5] 강제) — PaScaL에 없음. 최대원리상 무해 가정이나 로그의
  T 범위가 0.500에 정확히 걸림 → 실제 작동 가능성. 작동 시 벽 인접 에너지 보존을 미세하게 깸.
  **E7 후 갭 잔존 시 클리핑 OFF A/B 권장** (저비용).
- CPU↔GPU OB 스칼라 경로 차이(메모리 기록) — RBC NOB에는 일관, 본 사안 무관.

## 6. 판정 실험 E7 (job 29957, gpu02, 실행 중)

256×256×256 (수평 2×, z=수렴된 256), 수평 보간 웜스타트(t=8000), dt≈0.007, 통계 t≈8560–11150,
ETA ~14h. 예측:
- **E7 → Nu ≈ 9.6–10, θ_c ≈ 0.065–0.071**: 완전 종결. 결손의 최종 분해 =
  ① dW 아랫벽 면 누수 버그(수정 완료, 증상) ② z-해상도(0.0425→0.0565) ③ 수평 해상도
  (0.0565→~0.07). Kim 2023의 "128³" 기술은 실제 프로덕션 격자가 아님.
- **E7 → 0.057 유지**: 해상도 전축 수렴에도 갭 → 부록 B 벽항(mbc/ebc) 및 예측자 (1/ρ̂)Gp
  차이의 정밀 감사로 이행.

### 6.2 E7b 결과 (2026-07-05 판독) — 접근 지속, 평형 미도달 → E7c

깨끗한 통계 창(t=11640–14512, 2870 t.u.)의 시간평균: **⟨θ_c⟩_t = 0.0614**, **⟨Nu⟩ = 9.97**.
단 신호가 아직 정상상태가 아니다: 누적평균이 창 내에서 출렁(0.0621→0.0604→0.0614)이고

수평 배증 후 7500 t.u.가 지나도 셀 패턴의 구조 조정이 계속되는 것 — Pr=2547의 느린 평형
시간척도(Horn: 5000–10000 t.u.)와 일치한다.

**해상도 이력**: 0.0425(클린 128³) → 0.0565(z-수렴) → 0.0614+ (h-256, 평형 진행 중) → 0.071

T-클리핑) 감사.
