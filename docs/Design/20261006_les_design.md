# LES(와점성 SGS) 설계 — 채널 검증 → IBM 실린더 (2026-10-06, 설계만; 코드 없음)

> 사용자 지시: "channel 로 검증하고, 나중엔 실린더 IBM. 벽을 고려한 LES 모델을 선정·설계 (코드는 아직)".
> 선정 기준 두 가지가 모델을 거의 결정한다:
>   (K1) **벽 근처 ν_t 가 감쇠함수 없이 저절로 → 0** (Smagorinsky 는 벽에서 O(1) 이라 van Driest 가 필요)
>   (K2) **IBM 실린더에서도 그대로** — 벽 거리(van Driest)·균질방향 평균(동적 모델) 을 요구하지 않을 것

## 1. 후보 비교

| 모델 | 벽 거동 ν_t | 필요한 것 | 2D/층류에서 | IBM 적합 | 비고 |
|---|---|---|---|---|---|
| Smagorinsky + van Driest | y⁰ → 감쇠함수로 보정 | **벽 거리**, C_s | ν_t ≠ 0 (순수 전단에도) | ✗ (벽 거리 정의 곤란) | 참조 Fortran 의 `Const-Smagorinsky` 가 이것 (Es_Retau/Ap 감쇠) |
| 동적 Smagorinsky (Germano–Lilly) | 동적으로 y³ 근사 | 시험 필터 + **평면 평균**(채널 x,y) | 0 에 가까움 | △ (라그랑주 평균 필요 — 무거움) | 채널 검증의 "황금 기준" 이지만 실린더엔 부담 |

## 2. 선정
1. **1차 = WALE** — (K1)(K2) 모두 만족하고 상수 하나(C_w), 채널 참조 데이터 풍부.
2. **2차 = Const-Vreman** (참조 Fortran 과 동일 상수) — 같은 커널 구조(∇u → 대수식)라 WALE 과 **한 인터페이스 안에
   분기 하나**로 들어간다. Fortran 과의 **코드 간 비교**(같은 격자·같은 모델)가 가능해져 LES 구현 검증에 가치가 크다.
3. (예비) σ-model 은 실린더 단계에서 같은 인터페이스에 추가. 동적 Smagorinsky 는 채널 "기준선" 이 필요할 때만.
   Smagorinsky+van Driest 는 (K2) 위반이라 제외.

## 3. 우리 코드에 어떻게 얹히나 — 새 커널은 ν_t 하나뿐
가변물성(NOB) 경로가 이미 **∇·[μ̂(∇u+∇uᵀ)]·(C_μ/ρ̂)** 를 음해(CN ADI, 물성 lag) 로 풀고, 참조 Fortran 의 LES 도
정확히 `Mu = ν_t/ν + 1` 을 그 자리에 넣는 구조(POD/Equation.md §4). 따라서:
- **ν_eff = ν(1 + ν_t/ν)** 를 μ̂ 필드로, 1/ρ̂ ≡ 1 → `property_access.hpp` 의 템플릿 축에 **`EddyViscosityProperties`
  (μ̂ = Field, 1/ρ̂ = UnitArray)** 를 추가해 `momentum::solve_eddy_viscosity(...)` 비템플릿 공개 함수 두 벌 생성
  (rhs·system·couple·block_couple·solve — 상수판/가변판과 같은 식, 컴파일 타임 접힘). 식 정본은 그대로 한 곳(D3).
- 에너지(RBC/열 cavity LES 는 나중): κ_eff = κ + ν_t/Pr_t 를 κ̂ 로, dκ̂/dT·d(1/ρ̂Ĉp) 는 ZeroArray — 같은 템플릿 축.
- **ν_t 커널** `physics/sgs.{hpp,cpp,cu}` + `sgs_stencil.hpp`(MPMSTD_HD 공용 식): 셀중심 ∇u 9성분
  (대각 = 면 차분, 비대각 = 4점 평균; 벽 ghost 는 기존 value/mirror 정책 그대로 읽음) → 모델식 → ν_t(셀중심)
  → μ̂ = 1 + ν_t/ν 를 Field 에 기록. ghost μ̂: **벽 ghost = 1 (ν_t = 0)** — 벽 면 보간 점성이 정확히 ν 가 되어
  SGS 응력이 벽에서 0. 주기 축은 halo 교환.
  - WALE: g = ∇u, S = sym(g), S^d = sym(g²) − ⅓ tr(g²) I,  ν_t = (C_w Δ)² (S^d:S^d)^{3/2} / [(S:S)^{5/2} + (S^d:S^d)^{5/4} + ε]
    , Δ = (Δx Δy Δz)^{1/3} (z 스트레칭이면 국소 Δz).
  - Vreman: α_ij = ∂u_j/∂x_i, β_ij = Σ_m Δ_m² α_mi α_mj (방향별 Δ_m — 격자 비등방성 내장),
    B_β = β₁₁β₂₂−β₁₂² + β₁₁β₃₃−β₁₃² + β₂₂β₃₃−β₂₃²,  ν_t = C_v √(B_β/(α_ij α_ij)), α_ijα_ij < 1e-14 → 0 (Fortran 1:1).
  - 둘 다 ν_t ≥ 0 클립. 시간 처리는 NOB 와 동일(uⁿ 으로 ν_t 계산 → 그 스텝의 음해 밴드에 lag 사용).
- 설정 `[les] model = none | wale | vreman`, `c_w = 0.325`, `c_vreman = 0.036`(= 2.5·0.12², Fortran 동일; Vreman 원래
  값 0.07 도 입력으로 가능), `pr_t = 0.7`. `model = none` 이면 기존 상수 경로 그대로(비트 불변 게이트).
- 통계: ⟨ν_t⟩(z)/ν 프로파일 + 벽 근처 멱지수(log-log 기울기, WALE y³ 확인) 를 채널 통계에 추가.
- GPU: ν_t 커널 .cu 쌍둥이 1개. 비용: 스텐실 1회 + 가변 경로 ~1.4× — LES 격자가 DNS 의 1/10~1/100 이라 무의미.
- IBM 대비: ν_t 는 벽 거리·평균이 없으므로 고체 내부에서 0 으로 마스킹하는 한 줄 외엔 변경 없음.

## 5. 실린더(IBM) 단계로의 연결 — 미리 못 박는 것
- 모델은 국소 대수식만 → IBM 과 직교. σ-model 추가 시 ∇u 의 3×3 특이값(해석식, Nicoud 2011 §) 커널만.
- IBM 자체는 별 설계: 직접 강제(discrete forcing) + 유령셀/보간, 압력 솔버는 그대로(DCT/FFT 격자 유지가 전제 →
  고체는 강제항으로만). 실린더 검증 Re_D 100(층류, 2D) → 3900(LES, Parnaudeau et al. 2008) 순서가 자연스럽다.
