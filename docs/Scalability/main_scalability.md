# rbc_nob 전체 스텝 측정 — 어디에 시간이 가는가 (2026-10-17)

`apps/rbc_nob/main.cpp` 의 시간 루프를 호출 단위 17 구간으로 재고(plan.md §1·§2), 256³·512³ strong / weak 를 1노드 np ≤ 4 로 돌렸다.
200 스텝 중 워밍업 50 제외, 반복 2–3회 중 step_total 중앙값 런. 단위 ms/step(랭크 max). 수치 게이트: np·하드웨어에 무관하게 모니터 값 동일.

## 2. Strong / weak 효율 (np 1 → 4)

| | H200 256³ | H200 512³ | V100 256³ | H200 weak 256³/랭크 | V100 weak 256³/랭크 |
|---|---|---|---|---|---|
| np 2 | 80 % | 95 % | 104 % | 94 % | 96 % |
| np 4 | **61 %** | 90 % | 94 % | 93 % | 90 % |

np 4 에서의 확장 손실(= np 를 늘려도 안 줄어드는 양)은 어디서나 momentum_solve 가 1위, scalar_solve 가 2위. 통신(TDMA Alltoallv·halo)은 0.3–2 ms 로 아직 주범이 아니다.
