## 계산시간 산출 방법 (중요)

로그 파일(`logs/dhvc_gpu_*.log`)에는 **벽시계 시간 출력이 없다.** 솔버는 100 step마다
물리량(`step/t/dt/div/Re/KE/Nu/Trms`)만 찍고 마지막 `done` 한 줄로 끝난다 — elapsed / ms-step /
시작·종료 시각 기록 없음.

대신 stats 파일(`stats_t60.dat … stats_t240.dat`)이 **고정된 시뮬레이션 시각(t=60,90,…에 30단위
간격)에 디스크에 기록**되므로, 그 파일들의 **mtime(파일 수정 시각) 차이 = 실제 계산 시간**이다.

```
ms/step  = (stats_last.mtime − stats_first.mtime) × 1000 / (step_last − step_first)
계산시간 = 전체 iteration × ms/step
```

따라서 표의 계산시간은 mtime 기반 **복원치**다(±수 분~수십 분). 단, ms/step은 각 런 내내 ±5%
이내로 일정해 신뢰할 만하다. 정확한 측정을 원하면 step 루프 앞뒤로 `MPI_Wtime` 타이머를 추가해
`done` 라인에 출력하도록 하면 된다.

## 런별 상세

### Ra = 1e5  (`out_1e5`, `input_fig7_gpu_1e5.toml`)
- 하드웨어: gpu01, 2×A100, 분할 1×1×2 / 격자 384×192×96 / ν=2.6458e-03, α=3.7796e-03
- cold start(perturb=0.05), t_end=240, 전체 73,300 step
- stats span: t60(11:04:04)→t240(11:56:38) = 3,154 s / 53,700 step → 58.7 ms/step
- 계산시간 ≈ 1h 11m
- 결과: Re_d*=5.30 (target 5.78)

### Ra = 1e6  (`out_1e6`, `input_fig7_gpu_1e6.toml`)
- 하드웨어: gpu01, 2×A100, 분할 1×1×2 / 격자 384×192×96 / ν=8.3666e-04, α=1.1952e-03
- cold start, t_end=240, 전체 94,290 step, restart → `restart_1e6_t240`
- stats span: t60(11:22:02)→t240(12:24:35) = 3,753 s / 65,200 step → 57.6 ms/step
- 계산시간 ≈ 1h 30m
- 결과: Re_d*=10.16 (target 11.01)

### Ra = 1e7  (`out_1e7`, `input_fig7_gpu_1e7.toml`)
- 하드웨어: gpu01–02 (2노드), 4×A100, 분할 1×1×4 / 격자 832×416×192 / ν=2.6458e-04, α=3.7796e-04
- warm-start ← `restart_1e6_t240`(cross-mesh interp), t_end=240, 전체 226,485 step, restart → `restart_1e7_t240`

### Ra = 1e8  (`out_1e8`, `input_fig7_gpu_1e8.toml`)
