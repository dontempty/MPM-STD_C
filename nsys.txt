GPU Profiling Guide
We have enabled GPU program profiling on our server using Nsight Systems and Nsight Compute.
You can perform profiling by loading the nvhpc/23.7 module.

1. Identify Hotspots with Nsight Systems
First, you can check for bottleneck functions (hotspots) using Nsight Systems.

Bash
# Load the environment module
module load nvhpc/23.7

# Run Nsight Systems profiling
nsys profile --trace=mpi,cuda,nvtx -o <Report file name> mpirun <executable file name> <input file name (option)>
2. Analyze Kernels with Nsight Compute
Once you identify the target functions, you can use Nsight Compute to profile and optimize them at the kernel level.

Bash
# Run Nsight Compute profiling via Slurm
srun -N <number of node> -n <tasks per node> ncu --kernel-name <kernel_name> --set full --launch-skip 1 --import-source yes --launch-count 1 --target-processes all -f -o report_%q{SLURM_PROCID} <executable file name> <input file name (option)>
